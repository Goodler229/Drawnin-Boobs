# Нейромапа з синхронізацією

Нотатки, граф зв'язків, редактор схем. Вхід за поштою через IMAP, дані синхронізуються між пристроями.

    server/   Node.js-сервер (вхід через IMAP + сховище + веб-версія)
    desktop/  застосунок для macOS і Windows (Electron)

## 1. Сервер
Потрібен Docker (або Node.js 18+).

    cd server
    cp .env.example .env      # вкажіть IMAP_HOST та ALLOWED_DOMAINS
    docker compose up -d --build

Без Docker: `npm install && IMAP_HOST=imap.company.com node server.js`.
Відкрийте http://сервер:3000 - це вже працююча веб-версія.

**Обов'язково поставте HTTPS** (Caddy, nginx, Traefik) і `TRUST_PROXY=1`: пароль від пошти передається на сервер під час входу.

Змінні: `IMAP_HOST` (обов'язкова), `IMAP_PORT` (993), `IMAP_SECURE` (true), `ALLOWED_DOMAINS` (список доменів через кому),
`IMAP_USER_IS_EMAIL=false` (якщо IMAP-логін без @домену), `IMAP_REJECT_UNAUTHORIZED=false` (самопідписаний сертифікат),
`SECRET`, `DATA_DIR`, `PORT`.

## 2. Десктоп-застосунок для користувачів (macOS і Windows)
Користувач встановлює програму, вводить email і пароль від пошти - і все синхронізується.

1. У `desktop/config.json` вкажіть адресу вашого сервера (тоді користувачам не треба її вводити):

        { "server": "https://notes.company.com" }

2. Зберіть інсталятори одним із способів.

**А) Автоматично через GitHub Actions (рекомендовано, потрібні обидві ОС)**
Покладіть цю папку цілком у репозиторій GitHub і зробіть push. У вкладці Actions запуститься збірка "Build desktop".
Через кілька хвилин у розділі Artifacts будуть `windows-installer` (.exe) і `macos-installer` (.dmg для Intel та Apple Silicon).
Запустити вручну: Actions -> Build desktop -> Run workflow. Для тегу `v*` збірка теж запускається.

**Б) Вручну (Node.js 18+, кожен інсталятор збирається на своїй ОС)**

        cd desktop && npm install
        npm start            # перевірка
        npm run dist:win     # на Windows -> dist/*.exe
        npm run dist:mac     # на macOS   -> dist/*.dmg

Без підпису застосунку система покаже попередження при першому запуску:
Windows SmartScreen: "Докладніше" -> "Все одно запустити"; macOS: правий клік на програмі -> "Відкрити".
Щоб прибрати попередження, потрібні сертифікат Windows і Apple Developer ID.
Автооновлення немає: нову версію встановлюють поверх старої.

## Як це працює
- Пароль лише перевіряється спробою входу на IMAP-сервер і не зберігається. Далі видається токен на 30 днів.
- Кожен користувач має свої дані (файл у `data/users/`). Копіюйте папку `data` для бекапу.
- Синхронізація: кожні 15 с і через 1,5 с після змін. Конфлікти вирішуються по елементу: перемагає остання зміна нотатки чи схеми.
- Працює офлайн: зміни зберігаються локально й відправляються, коли з'явиться зв'язок.
- Дані на сервері не шифруються наскрізно: адміністратор сервера має до них доступ.

## Керування (виділення та полотно)

**Схеми**
- Рамка виділення: затисніть ліву кнопку на порожньому місці й тягніть.
- Ctrl/⌘ або Shift + клік додає чи знімає фігуру з виділення. Ctrl/⌘+A виділяє все, Esc знімає виділення.
- Виділену групу можна рухати, міняти колір і видаляти (Delete).
- Полотно безмежне: рух затиснутим пробілом, середньою кнопкою миші, інструментом «✋ Рух» або прокруткою трекпада. Масштаб: Ctrl/⌘ + колесо чи щипок, кнопки − / + у панелі, «100%» скидає вигляд.

**Граф**
- Ctrl/⌘ або Shift + клік по вузлу виділяє кілька вузлів, рамка по порожньому місцю теж.
- Перетягування виділеного вузла рухає всю групу. Звичайний клік відкриває нотатку, Esc знімає виділення.
